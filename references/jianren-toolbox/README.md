## 参考的使用体验

- 输入 `Y`/`YY` 调出紧凑工具箱（历史资料，实际命令会随版本改变）。
- 图形修改、文字、尺寸、图块等高频功能集中在可迅速调用的界面。
- 用户自定义快捷键/命令缩写，频繁绘图时尽量少弹出复杂向导。
