# 第三方工具使用体验 → YangCAD 自主功能对照

| 用户需求/体验 | 参考工具 | YangCAD 当前实现 | 下一步 |
|---|---|---|---|
| 菜单访问大量 CAD 工具 | 源泉设计 | Ribbon 分组 + 停靠工具箱（本轮静态） | 用分类整理，不复制完整菜单 |
| 弹出紧凑常用工具面板 | 贱人工具箱 | Palette 常用按钮 + PGP 快捷键 | 按真实需求增加工具搜索 |
| 切割提取大样 QG | 源泉设计 | `YGDETAIL` 矩形 V1 静态 | 支持选闭合多段线、复杂对象策略 |
| 图层移动/状态快捷操作 | 两者常见体验 | `YGLAYER`、合并/显隐/冻结/锁定 | 真机测试嵌套/外参层 |
| 直线转折断线 | 贱人工具箱相关功能 | 仅需求已确认 | 实现 Z 折断符号，保留端点/属性 |
| 文字、引线快速处理 | 两者 | `YGLEADERFIX` 静态 | 真机箭头/文字定位/Undo |
| 批量复制/出图/标注处理 | 两者 | 部分基础 MCP/Batch 已有 | 按用户新任务逐步开发 |

注意：此处仅比较**功能概念和交互**，不包含第三方源码、界面素材或未经验证的精确版本实现。
