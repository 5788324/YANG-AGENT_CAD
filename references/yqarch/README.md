## UI/功能参考（不复制素材）

- 顶部菜单/命令调用、快捷键/工具命令索引。
- QG：切割提取大样的框选/裁切/比例及标注处理经验。
- 绘图、文字、尺寸、图块与图层批处理。

## YangCAD 对照

- 已有静态候选 `YGDETAIL`：目前矩形裁切，不能冒称完整 QG 功能。
- 已有 `YGSCALE`、`YGLAYER`；闭合多段线裁切和复杂块选项在规划中。
