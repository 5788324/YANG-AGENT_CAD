# YangCAD 界面与交互规范（中文）

## 设计目标

1. **傻瓜式**：尽量“选对象 → 点操作 → 完成”，通常不超过两次必需输入。
2. **少看字**：工具卡片一行说明，技术字段（MCP、schema、Undo、unsupported）进高级设置/诊断。
3. **原生**：沿用 CAD 的窗口选择/命令行/属性/撤销习惯，避免浮层阻挡绘图。
4. **不抢焦点**：YangCAD Ribbon 不强制替代 CAD 原生 Home/常用；PaletteSet 可停靠可隐藏。
5. **用结果说话**：展示“已处理 N 个 / 跳过 M 个”，有失败才展开明细，不把 Worker 启动当成工作完成。

## 当前 UI

- Ribbon 的“常用工具 / 连接与设置”分组；Toolbox 顶部五个命令快捷入口；Revit/图片两个专业任务卡片。
- `YGKEYS` 维护 acad.pgp 缩写；Ctrl/Shift 组合键走原生 CUI。
- 控制中心：系统主题 / 快捷键 / 关于，About 由编译版本与实际加载路径驱动。

## 后续演进（未开发）

- 工具箱按分类筛选、收藏/最近使用、搜索；只有功能足够多时才启用，避免空分类。
- 小型可呼出的命令搜索框（仅在用户明确需要时开发），不全局 Hook 键盘。
- 选中对象后按对象类型推荐工具（仅辅助，不自动修改）。

## UI 回归验收

AutoCAD/Civil 3D 2024：启动 CAD 保持原生 Tab；YangCAD 入口显示；Palette dock/float 不挡命令；主题三种可切；快捷入口实际命令可调；About 的版本、宿主与 DLL 路径准确。
