状态：**SOURCE CANDIDATE / WINDOWS_NOT_TESTED**，只通过源码/CI 仍不能宣称 Windows AutoCAD 2024 可以运行、Undo 成功或稳定发布。

## 操作

执行 `YGOUTSIDE`（CAD 命令、停靠工具箱按钮、YGKEYS/PGP 快捷键管理），三种边界：
- Rectangle：两个角点建立 WCS XY 矩形；
- Select：选择当前空间内已闭合、零宽度、WCS XY 的 LWPOLYLINE；
- Draw：依次点直边顶点，回车闭合，不在当前图纸创建临时源边界。

第一遍使用 `CadTransactionRunner.ReadContext` **只读预览**，列出扫描数、待删除数、待修剪数、内部新片段数、安全跳过数及部分警告；默认 No，一次明确 Yes 才执行。确认后 `WriteContext` 内重新计算并比较预览指纹，若受影响对象/范围已变化则拒绝。所有新增、原对象 Erase 均由调用方的同一 AutoCAD Transaction 控制；真正的原生 `_.U` 效果须实机证明。

## V1 几何语义（不要扩大宣称）

使用 PR #14 `PolygonBoundary2d` 的**完全相同共享源码**（直接复制 Git Blob，避免不一致的第二几何算法）。允许凸、凹的**无自交、无 bulge 直边**多边形，拒绝非闭合/弧边/退化边界。

- 二维边界作为整个当前空间的 **XY 平面投影区域**，对实体各自的 Z/标高不构成三维裁切体。LINE 保留几何端点和 Z 插值。斜平面 ARC/CIRCLE 不做裁切。
- **完全在内**：保留原始对象；**可靠证明完全在外**：原对象可删除，采用 AABB 四角、边界顶点与边界边相交检查；即使复杂对象跨界不能精确修剪，也不会仅凭包围盒中心就在外将其删除。
- **部分相交的 LINE/ARC/CIRCLE/零宽 LWPOLYLINE**：对真正直线、圆弧交点分段，插入保留的内部曲线，再删除旧曲线。LWPOLYLINE 的跨界新片段可能变为独立 LINE/ARC，原 Handle / 非几何附加数据可能改变。全在内的 Polyline 不拆散。
- **无法安全裁切的跨界复杂对象**（块、尺寸、文字、关联填充、外参等）：跳过，并有计数/告警。不删除源边界、不修改块内部，不更改外部 DWG。
- 动态块、含属性块、外参 BlockReference、图片/PDF 底图、布局视口和关联 HATCH 即便位于外侧也默认保护；锁定、冻结、关闭图层中的对象不参与删除。普通无关联对象在可严格证明处于外侧时允许删除。
- 扫描最多 100000 个对象，实际改变最多 10000 个，输出新曲线片段最多 20000 个。警告文本最多显示 16 个，但 skipped 数量保留。
- 对于复杂实体仅以 DB 的 GeometricExtents 轴对齐包围盒做保守完全外侧判定，安全优先于最大清除率；对象特殊的代理/关联行为还需实机验证。
