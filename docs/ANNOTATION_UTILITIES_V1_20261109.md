# YangCAD 标注与文字工具 V1 — 2026-11-09

状态：**SOURCE CANDIDATE / WINDOWS_NOT_TESTED**。独立分支 feature/annotation-utilities-v1-20261109，基于 AutoCAD 2024 RC1 main，不依赖 Gemini 正在测试的 PR #16，也不修改源泉/贱人工具箱。静态检查不等同于真实 Windows .NET Build、NETLOAD、DWG、原生 Undo 通过。

## YGDIMTXT — 选改过显示文字的尺寸标注
- 扫描当前模型空间或当前布局（不进入块定义或外参），可 All 全部或 Selection 指定范围。
- AutoCAD 原生 Dimension.DimensionText 为空表示默认实际测量值；非空且不只是单独 <> 才认为用户覆盖了显示文字。
- 包括手改数值（如把 595 改成 600）、用 <> 表示真实数值并附注前后缀、以及隐藏文字（空格或 "."）。**不等于判定标注几何与文字位置是否拖动过**，只处理“文字内容覆盖”。
- 输出被筛选图元的 CAD 高亮/预选集和数量；只读，不修改尺寸测量、文字、标注样式、尺寸关联或当前图层。一次扫描上限 20 万实体。

## YGSLOPE — 标斜率
- 基准：Section（剖面二维，坡度=|ΔY|/|ΔX|）或 Plan3D（三维真实高差，坡度=|ΔZ|/sqrt(ΔX²+ΔY²)）。这是**两种不同定义**，不可混用。用户可以选择现有 LINE 或两点测量；不支持被取点精度不足导致水平投影重合/竖直无穷坡。
- 字符：Degrees 度数=atan(坡度)×180/π；Percent 百分比=坡度×100%；Ratio 1:X=1:(水平长度/绝对高差)；零坡度的 Ratio 显示 1:∞。默认 Percent，文本小数保留到 2 位，坡度取绝对值，下坡方向用箭头表示。
- **推荐几何：独立短指示线＋两段原生 LINE 箭翼＋一个原生 MTEXT**。指示线在参考 LINE 中段、按法向指定净偏移，箭头指向较低的一端，文字沿指示线排布且转正以便阅读。
- 不修改用户参考 LINE，不会把斜率标注冒充为会自动跟踪源线的关联对象；V1 后续如参考线改变需重新标注。各图元同一 Transaction 提交。

## YGTBOX — 文字加框
- 选中一组原生 TEXT/MTEXT，可选 Rectangle 四边矩形或 Circle 圆形；输入外扩留白距离（mm）。
- 对 MTEXT 使用 GetBoundingPoints 和 ActualWidth，避免以过大的编辑框宽度代替显示文本宽度。对旋转的单行 TEXT 使用临时克隆旋转归零后测 GeometricExtents、再恢复四角，不触碰原文。
- 按文字方向生成可编辑原生 Polyline（矩形）或 Circle（圆），与文字共平面；矩形四边各向外偏移给定距离，圆为包围文字外接圆半径加指定距离（不是文字到圆周每一处的恒定距离）。
- 仅支持正常 WCS XY 平面的 TEXT/MTEXT；文字高度/宽度异常、无法取范围、非 XY OCS，整批拒绝以免错误框住文字。不自动与文字形成随动组，修改文字后需要重新加框。
- 文字框放在当前图层，不会修改原文字的内容、位置、旋转或原 Handle；当前层锁定、关闭、冻结则不创建。

## 配置与界面
- 设置：使用现有 %LOCALAPPDATA%/YangCADAgent/settings.json，记忆坡度基准/格式/文字高/线偏移，以及文字框形状/净偏移（毫米）。
- 单位：INSUNITS=0 默认为毫米（提醒用户），已支持 1 英寸、2 英尺、4 毫米、5 厘米、6 米、7 千米，其他拒绝。
- 命令 YGDIMTXT / YGSLOPE / YGTBOX，中文 Toolbox 三按钮、YGKEYS 别名，不覆盖贱人工具箱快捷键。

## 附件核对
用户本轮提供的 column_mark.lsp 含 CMK（柱截面尺寸文字）；beam_mark.lsp 虽名为 beam_mark，但文件头和实现同样以柱截面为中心，扩充了 CMKD 原生对齐标注；双线(1).lsp 是之前的 YGDL 双线命令。三份附件均没有上述三项新功能，**本 PR 不复制、覆盖或擅自合并这些 LISP 命令**。

## 首版风险与后续增强
- DimensionText 文字覆盖与用户拖动的标注文字位置不是同一概念；若用户真正需要按位置改动筛选，应添加专门规则，不能冒充现在的结果。
- Section 模式斜线从哪一点到哪一点依赖现有 LINE/坐标；Plan3D 使用 Z 高差。对应图纸平面视图/剖视图单位需正确。
- 指示线为独立原生图元而非关联尺寸；可后续增加动态预览、组合组/自动跟踪、百分比和 1:X 同时多行标注。
- 字体 SHX、旋转 DBText、各类对齐、宽文字框、不可见/隐藏/空 MTEXT 的几何返回行为须 Windows 实机测。
- 未自动框 MLeader、标注内部文字或 Revit 标注。未来可增加自动随动关联与批量更新。
