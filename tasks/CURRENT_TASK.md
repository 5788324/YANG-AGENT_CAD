# 当前任务 — 截图对应版本的 AutoCAD 2024 复测（2026-11-19）

在 Windows AutoCAD 2024 用本分支的实际提交编译并加载 DLL，记录提交及加载的 DLL 路径和 SHA-256。

1. 打开 YangCAD Ribbon，核对六个分组。在 100% 和常用 DPI 下分别检查下拉名称、图标和中文菜单。点菜单主体应展开列表，执行后组名保持。CAD 仍保留启动前选中的页签。
2. 工具箱窄停靠，确认双列文字可读。右键改一个缩写，保存和应用一次。正在画线时点 Ribbon 或工具箱按钮，应提示先结束当前命令；原绘图命令继续等待输入。
3. 用测试 DWG 点选板格，SLBP 只显示预览，SLB 才生成符号。用典型填充验证挖出并保留的两部分、原纹理位置和一次撤销。空结果或失败时核对图元无部分改写。圆弧或带内洞的填充需核对裁切结果；原生布尔失败且备用算法无法完整处理时应保留原图。裁切框完整覆盖原填充时，「挖出并保留」应无改动。
4. 保存一份测试 DWG，画一条线但暂不保存。界面内嵌当前图纸和高级设置留空路径都应提示保存。保存后确认生成的是正确副本。
5. 对其余新增工具先测一组代表性样本：文字左对齐与递增复制，梁柱尺寸标注，板受力符号。记录对象前后结果与一次撤销。

6. 在同一封闭板格里放两个板符号和一个普通标记块，框选执行 SLBFIX。预期只修正、去重板符号，普通块的 Handle、定义、位置不变。单次撤销后两个原板符号恢复。另测只选普通块，图纸无变化。

## 矩形板方向箭头

打开 [SLB_SUPPORT_DIRECTIONS.dxf](../tools/fixtures/SLB_SUPPORT_DIRECTIONS.dxf)，切到世界坐标系和俯视图，图形单位为毫米。需要保存时另存为测试 DWG。青线是 SLAB_OUTLINE，红线是 BEAM。在 SLBLAYER 中分别用 01 的下边梁线与青色轮廓设置图层，重开图后重新设置。用 SLBP 与 SLB 点相同板内位置，核对下表。

| 编号 | 箭头预期 |
|---|---|
| 01 | 1 个，向下。板内另有普通块供框选测试。 |
| 02 | 2 个，向下与向右。 |
| 03 | 2 个，向左与向右。 |
| 04 | 3 个，向右、向上、向左。 |
| 05 | 4 个，四侧各一个。 |
| 06 | 0 个，预览只显示轮廓，布置不插入块。 |
| 07 | 2 个，对着旋转板的两条红色相对边。轮廓为顺时针。 |
| 08 | 1 个，向下。两段梁线重叠，总覆盖正好半边。 |
| 09 | 0 个。下边有横穿线和相距 10 mm 的平行线，上边梁线高 100 mm，左边重叠短线合计不足半边。 |

1. 在 01 放好方向符号，删除唯一的红色梁线，再框选符号和普通块执行 SLBFIX。方向符号应移除，普通块保留。原生撤销一次应恢复符号，红色梁线仍保持删除状态。再用 SLBP 预览，确认只显示轮廓。
2. 02 删除一侧梁线并执行 SLBFIX，只去掉对应方向的箭头。取消图层配置后再修正，方向符号应保留。
3. 梁线的原判定为距轮廓边不超过 1 个图纸单位且覆盖至少半边。未指定板轮廓时，复测旧闭合梁线识别和单向／双向板符号。

## Core Console 自动检查

在 Windows AutoCAD 2024 打开上面的 DXF，原样另存成测试 DWG。使用已经编译的本分支 DLL，保留其同目录依赖。命令可以在仓库目录的 PowerShell 里运行，按实际安装路径替换参数。

```powershell
python tools/run_slab_core_console_smoke.py --core-console "C:/Program Files/Autodesk/AutoCAD 2024/accoreconsole.exe" --dll "artifacts/bin/2024/AutoCAD/YangCAD.AutoCAD.dll" --dwg "D:/CAD-Test/SLB_SUPPORT_DIRECTIONS.dwg"
```

脚本检查九个板格、输入图元、符号总数、零支承移除、一次撤销、减一侧箭头和普通块保留。退出码 0 需全部 15 项及完成标记通过。运行目录在 artifacts/slab-smoke-*，包含输入文件哈希、测试图副本、实际 SCR 和原始输出。若使用自定义板跨设置，须允许测试图的 4000–6000 mm 板跨。

Core Console 检查命令和 DWG 结果。Ribbon、工具箱、鼠标拾点和预览显示继续按上述 GUI 步骤验收。

旧版 RC1 和 PR #16/#17 的记录保留为历史证据。
